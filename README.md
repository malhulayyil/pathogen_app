# مشروع Flutter للبحث في مسببات الأمراض الغذائية

## الخطوات للتشغيل التلقائي عبر GitHub Actions

١) **ارفع** هذا المشروع إلى مستودع على GitHub في فرع `main`.  
٢) اذهب إلى تبويب **Actions** وستبدأ عملية البناء تلقائيًا.  
٣) بعد انتهاء العملية، انتقل إلى **Artifacts** وحمّل `app-release.apk`.  

*لا حاجة لأي بيئة Flutter محليًا.*
